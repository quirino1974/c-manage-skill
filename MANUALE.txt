manage-skill: manuale d'uso
===========================
Autore: Quirino Scaramastra

manage-skill esporta, cataloga e descrive le skill di Claude, e le sposta tra account diversi gestendo le chiavi API. Si usa dalla riga di comando (ms) o dalla finestra Qt (manage-skill-qt).

1. Installazione
----------------

    cd manage-skill      # la cartella del repository
    ./installa.sh

Lo script fa tre cose:
- crea l'ambiente Python .venv;
- installa l'SDK anthropic;
- crea il comando ms in ~/.local/bin.

Da quel momento ms funziona da qualsiasi cartella. In alternativa usa ./ms dalla cartella del programma.

Aiuto: ms --help e ms <comando> --help. Versione: ms --versione.

2. Cartelle
-----------

  Cartella                         Contenuto
  ------------------------------   --------------------------------------------------------------------------------------------------------
  manageskill/                     il programma Python; motore.py e servizi.py servono alla finestra Qt
  gui-qt/                          la finestra Qt in C++ e lo script compila.sh
  dati/config.json                 impostazioni facoltative (vedi §10)
  dati/account.json                registro degli account, senza chiavi
  dati/categorie.json              regole delle categorie e assegnazioni manuali
  catalogo/                        catalogo.html e catalogo.json, rigenerati a ogni ms catalogo
  manageskill/archivio/            tutte le esportazioni: skill singole (ms esporta), copie di sicurezza, _da-caricare/ (ZIP per claude.ai)
  manageskill/archivio/cloud/      esportazioni delle skill dell'account claude.ai (ms cloud esporta)
  ~/.config/manage-skill/chiavi/   chiavi salvate su file (solo se scegli file), fuori dal progetto

3. Da dove legge le skill (fonti)
---------------------------------

Solo le tue skill. Per evitare problemi di proprietà, il programma mostra ed esporta soltanto le skill create da te (e quelle di terze parti che aggiungi tu, con la loro licenza). Le skill di Anthropic presenti su claude.ai e quelle dei plugin dei marketplace non vengono lette. L'impostazione è "solo_utente": true in dati/config.json (predefinita); mettendola a false torna la vista completa, sotto la tua responsabilità.

  Fonte         Dove                                                                          Modificabile
  -----------   ---------------------------------------------------------------------------   ------------
  claude-code   ~/.claude/skills/<nome> (anche collegamenti ai progetti)                      sì
  progetto      <progetto>/.claude/skills/<nome> sotto le cartelle di radici_progetti (§11)   sì
  plugin        ~/.claude/plugins/**/skills/<nome> (letta solo con "solo_utente": false)      no
  claude-ai     ~/.claude/skills/synced/<account>/, la copia sincronizzata da Claude Code     no
  archivio      manageskill/archivio/<nome>/<data>/<nome>                                     no

L'origine indica chi ha creato la skill:
- tua: le tue skill;
- anthropic: le skill di Anthropic;
- plugin: le skill dei plugin.

Quando una skill si trova in più fonti e non indichi --da, il programma sceglie la copia in quest'ordine: claude-code, progetto, claude-ai, archivio, plugin.

4. Catalogo e descrizione
-------------------------

ms catalogo
~~~~~~~~~~~
Elenca tutte le skill con categoria, stato di attivazione (colonna ATTIVA), fonti, numero di file, dimensione e stato delle copie:
- ok: tutte le copie sono uguali;
- DIVERSE: almeno due copie hanno contenuti diversi.

Ogni volta salva catalogo/catalogo.html e catalogo/catalogo.json.

  Opzione                          Effetto
  ------------------------------   ---------------------------------------------
  --fonte claude-code progetto …   solo queste fonti
  --categoria social               solo una categoria (basta una parte del nome)
  --mie                            solo le tue skill
  --json                           stampa il catalogo in JSON
  --apri                           apre il catalogo HTML nel browser

Attiva o disattivata
~~~~~~~~~~~~~~~~~~~~
La colonna ATTIVA (nella finestra: Attiva, e Attivazione nel pannello delle copie) dice se Claude usa la skill:

  Valore              Significato
  -----------------   ------------------------------------------------------------------------------------------------------------------------------------------------------------
  attiva              Claude Code la carica e può usarla da solo
  solo manuale        si usa solo richiamandola con /nome (skillOverrides: "user-invocable-only" o disable-model-invocation: true nel frontmatter)
  attiva (compatta)   attiva, ma Claude ne vede solo il nome (skillOverrides: "name-only")
  disattivata         spenta con skillOverrides: "off" nei settings di Claude Code
  su claude.ai        la skill è solo su claude.ai: l'interruttore attiva/disattiva si vede solo sul sito (Impostazioni > Capacità > Skill), la copia sincronizzata non lo riporta
  non caricata        copia di manage-skill (archivio, terze parti): Claude non la usa da lì

Per Claude Code il programma legge skillOverrides in ~/.claude/settings.json e, per le skill di progetto, in <progetto>/.claude/settings.json e settings.local.json. Il passaggio del mouse sulla cella mostra il motivo.

ms descrivi <nome> [--da FONTE]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Mostra la scheda completa:
- categoria e origine;
- cartella e impronta;
- frontmatter, descrizione ed elenco dei file;
- tutte le copie;
- l'esito della validazione per la Skills API e del controllo dei segreti.

ms confronta <nome>
~~~~~~~~~~~~~~~~~~~
Confronta file per file tutte le copie della skill:
- + file presente solo nella seconda copia;
- - file presente solo nella prima;
- ~ file con contenuto diverso.

ms valida <skill> [--da FONTE]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Controlla le regole della Skills API:
- name presente, solo minuscole, numeri e trattini, al massimo 64 caratteri, senza le parole "anthropic" o "claude";
- description presente, al massimo 1024 caratteri;
- niente tag XML;
- dimensione al massimo 30 MB.

<skill> può essere un nome, una cartella o uno ZIP.

ms segreti <skill> oppure ms segreti --tutte
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Cerca chiavi API (Anthropic, AWS, GitHub, Slack), chiavi private, password e token scritti in chiaro, e file sensibili (.env, .netrc, id_rsa, …). Mostra il file e la riga, mai il valore. Con --tutte controlla tutte le skill di Claude Code e dei progetti.

Categorie
~~~~~~~~~
Le regole stanno in dati/categorie.json, che si crea al primo uso.

Come funzionano:
- ogni parola trovata nel nome vale 3 punti, nella descrizione 1 punto;
- le parole sono intere, quindi "post" non trova "posta";
- con l'asterisco finale una parola diventa una radice: certificaz*.

Per fissare a mano la categoria di una skill:

    "assegnate": { "mia-skill": "Finanza" }

5. Skill del cloud (account claude.ai)
--------------------------------------

Con "solo_utente": true (predefinito) qui compaiono ed escono solo le tue skill: le opzioni --tutte non aggiungono quelle di Anthropic.

claude.ai non ha un'API pubblica per scaricare le skill. Claude Code però ne tiene una copia sincronizzata sul PC, e manage-skill lavora su quella. La data di sincronizzazione compare in ogni elenco: per avere l'ultima versione apri Claude Code prima di esportare.

ms cloud elenco [--mie] [--json] [--api]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Mostra per ogni skill:
- il tipo: tua, Anthropic, esempio Anthropic;
- la categoria;
- la data di aggiornamento su claude.ai;
- i file e la dimensione;
- il confronto con la copia locale di Claude Code: uguale, diversa, assente.

Con --api aggiunge i metadati delle skill degli account API registrati: nome, id, versione. I file non ci sono, perché l'API non li fornisce.

ms cloud esporta
~~~~~~~~~~~~~~~~
Esporta su richiesta nella sottocartella manageskill/archivio/cloud/ del programma:

    ms cloud esporta --mie                    # tutte le tue
    ms cloud esporta --tutte                  # anche quelle di Anthropic
    ms cloud esporta altra-skill     # solo alcune, per nome

Ogni esportazione crea:

    manageskill/archivio/cloud/claude-ai_<org>_<utente>/<AAAA-MM-GG_HHMMSS>/
      skill/<nome>/      cartella completa della skill
      zip/<nome>.zip     pronto da ricaricare su claude.ai o nella Skills API
      indice.json        id claude.ai, tipo, impronta, nuova/uguale/cambiata, problemi API, segreti
      indice.html        catalogo dell'esportazione da aprire nel browser
    manageskill/archivio/cloud/claude-ai_…/ultima  ->  collegamento all'esportazione più recente

Alla fine il comando elenca le skill nuove o cambiate rispetto all'esportazione precedente.

Una skill con possibili segreti viene saltata e segnalata, mentre le altre vengono esportate lo stesso. Se l'avviso è un falso allarme, rilancia con --ignora-segreti.

ms cloud verso-api <account> [skill…] [--prova] [--forza] [--tutte] [--ignora-segreti]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Importa automaticamente le skill di claude.ai in un account API della Claude Console:
- una skill che nell'account manca viene creata;
- una skill già presente e cambiata da quando manage-skill l'ha caricata l'ultima volta diventa una nuova versione;
- una skill uguale viene saltata ("già aggiornata"). Con --forza viene ricaricata comunque.

Senza nomi prende tutte le tue skill, con --tutte anche quelle di Anthropic. Le skill con possibili segreti o che non rispettano le regole della Skills API vengono saltate e segnalate.

Il comando segnala anche quando sul PC c'è una versione più recente di quella su claude.ai: in quel caso valuta di aggiornare prima claude.ai, oppure usa ms importa <nome> --verso <account>, che carica la copia del PC.

Ciò che è stato caricato viene registrato in dati/sincronizzazioni.json, senza chiavi. È così che il programma sa cosa è cambiato.

    ms cloud verso-api lavoro-api --prova     # cosa farebbe
    ms cloud verso-api lavoro-api             # lo fa

Nella finestra Qt: scheda Cloud claude.ai, riga "Importa in un account API". Il pulsante agisce sulle skill selezionate, o su tutte le tue se non ne selezioni nessuna. "solo prova" è attivo per impostazione predefinita.

ms cloud storico
~~~~~~~~~~~~~~~~
Elenca le esportazioni presenti in manageskill/archivio/cloud/ con queste informazioni:
- data;
- numero di skill;
- quante sono cambiate e quante sono state saltate;
- data di sincronizzazione.

6. Esportazione in archivio
---------------------------

ms esporta <skill…> | --mie | --tutte [--da FONTE] [--ignora-segreti]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Crea manageskill/archivio/<nome>/<data-ora>/ con:
- la cartella della skill;
- <nome>.zip;
- skill.json, con fonte, impronta, file, problemi API e risultato del controllo dei segreti.

Se trova possibili segreti si ferma.

Esempi:

    ms esporta mia-skill
    ms esporta --mie
    ms esporta altra-skill --da claude-ai

7. Importazione verso un account
--------------------------------

ms importa <skill…> --verso ACCOUNT [opzioni]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
<skill> può essere uno di questi:
- un nome;
- una cartella con SKILL.md;
- uno ZIP;
- una cartella di archivio (quella con skill.json).

  Tipo di account   Cosa fa
  ---------------   ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  api               valida la skill, poi la crea con la Skills API. Se esiste già una skill con lo stesso nome ne crea una nuova versione
  claude-code       copia la cartella. Se la skill c'è già identica dice "già identica". Se è diversa si ferma: con --sovrascrivi prima salva la copia attuale in archivio, poi la sostituisce. Non scrive dentro un collegamento: in quel caso aggiorna la skill nel progetto
  claude-ai         prepara lo ZIP nella cartella dell'account o in manageskill/archivio/_da-caricare/<account>/. Lo carichi tu da claude.ai, Impostazioni > Capacità > Skill > Carica skill

  Opzione            Effetto
  ----------------   -------------------------------------------------------
  --prova            mostra cosa farebbe, senza modificare nulla
  --sovrascrivi      solo per claude-code, vedi sopra
  --da FONTE         da quale copia prendere la skill
  --mie, --tutte     importa tutte le tue skill, o anche quelle di Anthropic
  --ignora-segreti   procede anche con avvisi del controllo dei segreti

Esempi:

    ms importa mia-skill --verso lavoro-api --prova
    ms importa mia-skill --verso lavoro-api
    ms importa manageskill/archivio/cloud/claude-ai_…/ultima/zip/altra-skill.zip --verso locale --sovrascrivi
    ms importa --mie --verso altro-pc        # account claude-code con --cartella su un disco condiviso

8. Account e chiavi
-------------------

ms account elenco
~~~~~~~~~~~~~~~~~
Elenca gli account. locale è predefinito e corrisponde a ~/.claude/skills.

ms account aggiungi <nome> --tipo api|claude-code|claude-ai [opzioni]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

    ms account aggiungi lavoro-api --tipo api                  # chiede la chiave e la salva nel portachiavi
    ms account aggiungi lavoro-api --tipo api --chiave file    # oppure in ~/.config/manage-skill/chiavi (600)
    ms account aggiungi ci --tipo api --chiave env:ANTHROPIC_API_KEY
    ms account aggiungi profilo --tipo api --chiave ant        # usa il profilo della CLI ant
    ms account aggiungi progetto-x --tipo claude-code --cartella ~/progetti/x/.claude/skills
    ms account aggiungi web-lavoro --tipo claude-ai --cartella ~/Scaricati/skill-lavoro

Opzioni per gli account api:
- --workspace ID: workspace dell'organizzazione;
- --base-url URL: endpoint alternativo;
- --nota: un testo libero.

--sostituisci ridefinisce un account esistente.

ms account console [nome] [--workspace ID] [--dove keyring|file] [--sostituisci]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Configura in modo sicuro un account API della Claude Console. Il nome predefinito è console.

1. Su platform.claude.com crea una chiave API in Settings > API keys, nel workspace da leggere. Non usare una chiave Admin (sk-ant-admin…): viene rifiutata.
2. Lancia il comando e incolla la chiave quando la chiede. La chiave non viene mostrata.
3. Il programma prova subito la chiave sulla Skills API e salva account e chiave solo se funziona.

Lo stesso si fa dalla finestra Qt: scheda Cloud claude.ai > Configura account API (Claude Console).

Le skill della Console e quelle di claude.ai sono archivi separati. Una skill caricata su claude.ai non compare nella Skills API e viceversa: la scansione dice dove esistono skill con lo stesso nome.

ms account chiave <nome> [--dove keyring|file]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Inserisce o sostituisce la chiave. Si scrive senza eco e non compare mai a schermo.

ms account prova <nome>
~~~~~~~~~~~~~~~~~~~~~~~
Verifica l'account:
- per un account api controlla la chiave e conta le skill. Mostra solo l'inizio e la fine della chiave;
- per gli altri controlla la cartella.

Gli errori sono spiegati in chiaro, per esempio "chiave non valida o revocata (401)" oppure "permessi mancanti (403)".

ms account rimuovi <nome>
~~~~~~~~~~~~~~~~~~~~~~~~~
Toglie l'account e cancella la sua chiave dal portachiavi o dal file.

Regole sulle chiavi
~~~~~~~~~~~~~~~~~~~
- Le chiavi non vanno mai in dati/account.json, negli archivi o nelle esportazioni.
- Il portachiavi è la scelta consigliata. Usa il file solo se secret-tool non c'è. In quel caso il programma rifiuta il file se è leggibile da altri utenti.

9. Skill negli account API
--------------------------

  Comando                                     Effetto
  -----------------------------------------   -------------------------------------------------------------------------------------
  ms remoto elenco <account> [--tutte]        skill custom (con --tutte anche quelle di Anthropic): nome, id, versione, data
  ms remoto versioni <account> <nome>         versioni di una skill
  ms remoto elimina <account> <nome> [--si]   elimina la skill e tutte le sue versioni. Chiede di scrivere SI. Non si può annullare

10. Interfaccia di gestione (finestra Qt)
-----------------------------------------

È una finestra nativa scritta in C++ con Qt 6 (cartella gui-qt/). Non c'è nessun server e nessuna porta aperta: ogni pulsante avvia per un istante il motore Python (python -m manageskill.motore), gli passa la richiesta sullo standard input e legge la risposta in JSON. Quando chiudi la finestra non resta nulla in esecuzione.

Compilazione, da fare una volta (e dopo ogni modifica al codice C++):

    sudo apt install qt6-base-dev cmake
    gui-qt/compila.sh            # crea gui-qt/build/manage-skill-qt e il comando manage-skill-qt
    manage-skill-qt

compila.sh installa anche l'icona e la voce manage-skill nel menu delle applicazioni: la trovi cercando "manage-skill" nella panoramica di GNOME.

L'aspetto segue il tema chiaro o scuro del sistema. Per sceglierlo a mano: MANAGE_SKILL_TEMA=scuro manage-skill-qt (oppure chiaro). Nella barra in alto ci sono i contatori (skill totali, tue, da allineare, terze parti) e il pulsante Informazioni, con versione, copyright e licenza.

La finestra cerca il programma Python nella cartella in cui è stata compilata. Se sposti manage-skill, ricompila oppure imposta MANAGE_SKILL_DIR.

Ha cinque schede (Catalogo, Cloud claude.ai, Terze parti, Account e chiavi, Esportazioni) e un registro delle operazioni in basso.

- Catalogo:
  - tabella di tutte le skill, ordinabile, con ricerca e filtri: categoria, fonte, solo le mie, solo copie diverse;
  - quando le copie di una skill non coincidono, la colonna Stato dice "copie diverse (N)" e la colonna Più recente mostra ★, la fonte e la data della versione più nuova;
  - selezionando una skill, il pannello sotto la tabella elenca tutte le sue copie dalla più recente, con fonte, data, stato (★ più recente, uguale, più vecchia e diversa) e cartella. "Apri la cartella della copia" la apre nel file manager. Per le copie di claude.ai conta la data di aggiornamento sul cloud, non quella della sincronizzazione sul PC;
  - accanto alle copie c'è il riquadro Note sulla skill: scrivi e premi "Salva nota" (vedi §14). La colonna Note del catalogo ne mostra la prima riga;
  - Modifica…, oppure il doppio clic su una copia, apre l'editor della skill (vedi §15);
  - il doppio clic apre la scheda della skill con descrizione, copie, file, validazione, segreti, testo di SKILL.md e il pulsante per confrontare le copie;
  - con le caselle della colonna Nome scegli le skill su cui lavorare, poi la barra in basso esporta in archivio o importa verso un account;
  - solo prova è attivo per impostazione predefinita: toglilo per importare davvero, e la finestra chiede conferma.
- Cloud claude.ai:
  - skill dell'account con tipo, data, confronto con la copia locale e id;
  - pulsanti per esportare le selezionate, tutte le tue o tutte;
  - al termine propone di aprire l'indice dell'esportazione;
  - in basso, Configura account API (Claude Console)… guida la creazione dell'account, poi Scansiona le skill degli account API elenca le skill di tutti gli account API. Per ogni skill mostra id, versione, date e se esiste una skill con lo stesso nome sul PC o su claude.ai.
- Account e chiavi:
  - elenco degli account, con Nuovo account, Prova, Cambia chiave e Rimuovi (che chiede conferma);
  - la chiave si scrive in un campo password;
  - elenco ed eliminazione delle skill di un account API: per eliminare va scritto il nome della skill.
- Esportazioni: mostra dove stanno le esportazioni (manageskill/archivio/ e manageskill/archivio/cloud/) e il pulsante "Apri l'archivio". Elenca le esportazioni in manageskill/archivio/cloud/ e in manageskill/archivio/, con i pulsanti per aprire l'indice o la cartella.

Sicurezza delle chiavi: la chiave passa dalla finestra al motore solo attraverso lo standard input, quindi non è visibile tra i processi con ps. Il motore la salva nel portachiavi o nel file protetto e non la rimanda mai indietro.

10.1 Lingua
-----------

L'interfaccia è in italiano o in inglese:
- finestra: menu della lingua nella barra in alto (🇮🇹 Italiano / 🇬🇧 English). La scelta viene ricordata e la finestra si ricrea subito nella nuova lingua;
- riga di comando: MANAGE_SKILL_LINGUA=en ms … oppure "lingua": "en" in dati/config.json.

Le traduzioni stanno in manageskill/lingue/en.json, un solo dizionario per finestra, motore e riga di comando, generato da strumenti/crea_dizionario_en.py. Per correggere o aggiungere una traduzione modifica lo script e rilancialo. I nomi dei comandi e delle opzioni (ms catalogo, --prova…) restano uguali in tutte le lingue. I documenti inglesi sono MANUAL.en.txt, RELEASENOTES.en.txt e la parte inglese di COPYRIGHT.

11. Impostazioni (dati/config.json, facoltativo)
------------------------------------------------

    {
      "radici_progetti": ["/home/utente/progetti", "/home/utente/Documents/GitHub"],
      "escludi": ["node_modules", ".git", ".venv", "venv", "__pycache__", "data", "archivio"],
      "limite_mb": 30,
      "solo_utente": true,
      "lingua": "it"
    }

- radici_progetti: dove cercare le cartelle .claude/skills; se manca dati/config.json si usa ~/claudeworkspace;
- escludi: cartelle da non esplorare;
- limite_mb: dimensione massima per la Skills API;
- solo_utente: mostra solo le tue skill (vedi §3);
- lingua: it o en per la riga di comando.

12. Flussi tipici
-----------------

Copia di sicurezza delle skill del cloud. Apri Claude Code, poi:

    ms cloud esporta --mie && ms cloud storico

Allineare claude.ai e il PC.
1. ms cloud elenco --mie: le skill segnate diversa vanno guardate.
2. ms confronta <nome> per vedere le differenze.
3. Per caricare la versione locale su claude.ai: ms importa <nome> --verso <account claude-ai>, poi carica lo ZIP da Impostazioni.

Portare le tue skill in un'organizzazione API.
1. ms account aggiungi org --tipo api (chiede la chiave).
2. ms account prova org.
3. ms importa --mie --verso org --prova.
4. Se il risultato va bene, ripeti senza --prova.
5. Controlla con ms remoto elenco org.

13. Problemi comuni
-------------------

  Messaggio                                Cosa fare
  --------------------------------------   ---------------------------------------------------------------------------------------------------------
  Nessuna skill claude.ai trovata          apri Claude Code collegato all'account claude.ai, così sincronizza la copia
  Possibili segreti …                      togli la chiave dalla skill (meglio una variabile d'ambiente); se è un falso allarme usa --ignora-segreti
  chiave API non valida o revocata (401)   ms account chiave <nome>
  … esiste già con contenuto diverso       ms confronta <nome>, poi --sovrascrivi se vuoi sostituirla
  … è un collegamento a …                  la skill vive in un progetto: modificala lì
  Non trovo manage-skill in … (finestra)   ricompila con gui-qt/compila.sh o imposta MANAGE_SKILL_DIR
  Manca l'ambiente Python … (finestra)     esegui ./installa.sh nella cartella del programma

14. Note sulle skill
--------------------

Ogni skill può avere una nota tua: a cosa serve, da dove viene, cosa ricordare. La nota vale per il nome, quindi per tutte le copie della skill. Sta in dati/note.json e non finisce nelle esportazioni né negli account.

- Finestra: scheda Catalogo, seleziona la skill, scrivi nel riquadro Note sulla skill e premi Salva nota. Se svuoti il testo e salvi, la nota viene cancellata.
- Terminale: ms nota <skill> la legge, ms nota <skill> testo della nota la scrive, ms nota <skill> --cancella la cancella.

15. Modifica delle skill
------------------------

Dalla finestra si modificano i file di una skill: SKILL.md, i riferimenti, gli script.

1. Nel Catalogo seleziona la skill, scegli la copia nel pannello delle copie e premi Modifica…, oppure fai doppio clic sulla copia. Per le terze parti c'è il pulsante Modifica… nella loro scheda.
2. A sinistra c'è l'elenco dei file, a destra il testo. Nuovo file… aggiunge un file, per esempio references/esempi.md.
3. Salva (o Ctrl+S).

Regole di sicurezza:
- si modificano solo le copie di claude-code, dei progetti e delle terze parti. Le copie di claude.ai, dei plugin e dell'archivio si aprono in sola lettura. Per cambiare una skill di claude.ai modifica la copia locale e poi ricaricala;
- prima di ogni salvataggio la skill intera viene copiata in manageskill/archivio/<nome>/<data-ora>/;
- se il file è stato cambiato da un altro programma dopo l'apertura, il salvataggio viene rifiutato: riapri il file;
- dopo il salvataggio la skill viene ricontrollata (regole della Skills API, nome uguale alla cartella, possibili segreti) e gli avvisi compaiono subito;
- l'editor accetta solo file di testo UTF-8 fino a 1 MB e non scrive mai fuori dalla cartella della skill;
- se la copia di claude-code è un collegamento a un progetto, si modifica il file del progetto, cioè l'originale.

16. Skill di terze parti
------------------------

Skill scritte da altri, prese da un repository Git, da uno ZIP (file o indirizzo https) o da una cartella. manage-skill le tiene in manageskill/terze-parti/<nome>/, ricorda da dove vengono (dati/terze_parti.json), le aggiorna dalla sorgente e le sincronizza con gli account che scegli.

Dalla finestra, scheda Terze parti:
1. Aggiungi…: incolla la sorgente (per esempio https://github.com/anthropics/skills) oppure scegli una cartella o uno ZIP, e premi Cerca skill. Compare l'elenco con il numero di file, di script e di possibili segreti. Spunta le skill da aggiungere e gli account in cui sincronizzarle, poi premi Aggiungi le selezionate.
2. Aggiorna dalla sorgente: riscarica le skill selezionate, o tutte, e sostituisce quelle cambiate. La versione vecchia va in archivio. Se hai modificato qui una skill, l'aggiornamento si ferma; con forza la sostituisce comunque.
3. Destinazioni…: sceglie gli account in cui sincronizzare la skill selezionata.
4. Sincronizza con gli account porta le skill negli account di destinazione:
   - claude-code: copia la skill. Se nell'account la copia è stata modificata a mano dopo l'ultima sincronizzazione, si ferma; con forza la sostituisce, dopo averla salvata in archivio;
   - api: crea la skill o una nuova versione, solo se il contenuto è cambiato;
   - claude-ai: prepara lo ZIP da caricare.

   "solo prova" è attivo per impostazione predefinita.
5. Modifica…, Apri la cartella e Rimuovi. La rimozione salva la cartella in archivio e non tocca le copie già sincronizzate negli account.

Da terminale:

    ms terze anteprima https://github.com/anthropics/skills            # cosa contiene
    ms terze aggiungi https://github.com/anthropics/skills --percorso skills/canvas-design --verso locale
    ms terze elenco
    ms terze destinazioni canvas-design locale lavoro-api
    ms terze aggiorna                       # tutte; --forza per sostituire anche le copie modificate qui
    ms terze sincronizza --prova            # poi senza --prova; --verso <account> per uno solo
    ms terze rimuovi canvas-design

Sicurezza:
- manage-skill non esegue mai gli script delle skill di terze parti. Li elenca, nella colonna Script e nell'anteprima, perché tu possa controllarli prima di usare la skill con Claude;
- prima di ogni sincronizzazione viene fatto il controllo dei segreti;
- gli ZIP vengono estratti solo se non contengono percorsi pericolosi, e i download sono limitati a 50 MB;
- git clone non chiede mai credenziali: un repository privato va reso accessibile prima, per esempio con una chiave SSH.

17. Prompt per ricreare una skill
---------------------------------

Crea un testo da incollare in Claude (una nuova chat di claude.ai, Claude Code o un altro account) che ricostruisce la skill con la stessa struttura e gli stessi file. Serve, per esempio, a portare una skill in un account dove non puoi caricare ZIP, o a farla rivedere a Claude.

Il prompt contiene:
- le istruzioni per Claude: ricreare la skill esattamente, senza riassumere né migliorare il testo;
- dove installarla, in Claude Code o su claude.ai;
- l'albero delle cartelle;
- ogni file in un blocco con il suo percorso.

Ci sono due modalità:
- completo: tutti i file di testo, parola per parola. La skill torna identica;
- essenziale: solo SKILL.md più l'elenco degli altri file, che Claude riscrive seguendo le istruzioni. È più corto.

I file binari e quelli troppo grandi (oltre 200 KB, o oltre 600 KB in totale) vengono solo elencati. Il prompt è nella lingua scelta per l'interfaccia.

Sicurezza: le righe in cui il controllo dei segreti trova chiavi, token o password vengono oscurate con un segnaposto, e il prompt dice quante sono. In chat non finisce nessuna credenziale.

- Finestra: nel Catalogo seleziona la skill (e, se vuoi, una copia precisa nel pannello delle copie), poi premi Prompt…; oppure Prompt per ricreare la skill nella scheda della skill. Si apre l'anteprima, modificabile, con la scelta della modalità e i pulsanti Copia negli appunti e Salva come file….
- Terminale:

    ms prompt mia-skill              # stampa il prompt
    ms prompt mia-skill --copia      # lo copia negli appunti (wl-copy, xclip o xsel)
    ms prompt mia-skill --essenziale --file ~/prompt.md
    ms prompt altra-skill --da claude-ai   # dalla copia di claude.ai
